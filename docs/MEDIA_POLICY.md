# 미디어 변환 정책

공개본(`_web/`, → https://suokkim.github.io/karts/)에 들어가는 이미지·영상·PDF 를
어떤 크기·포맷으로 맞출지의 **정본**. 숫자는 `_optimize.py` 상단 상수와 1:1 로
대응하므로 한쪽을 바꾸면 다른 쪽도 같이 고친다.

원본(2.4GB)은 학기 폴더에 그대로 두고, 공개본만 이 정책으로 변환한다.

## 이미지

| 항목 | 값 |
|---|---|
| 포맷 | **JPEG** (progressive, `optimize=True`) |
| 품질 | **78** (PDF 페이지는 72) |
| 색공간 | sRGB. 투명 배경(PNG·RGBA)은 **흰색**으로 합성 |
| 방향 | EXIF Orientation 을 픽셀에 반영하고 태그는 버린다 |
| 크기 | 아래 규칙 |

### 크기 규칙 — `fit()` 하나로 통일

사진이든 스캔이든 PDF 페이지든 **같은 함수**를 쓴다. (예전엔 사진은 장변 기준,
PDF 는 단변 기준이라 2489×1400 슬라이드와 1267×6000 포스터가 섞여 있었다.)

| 이미지 모양 | 규칙 | 예 |
|---|---|---|
| 보통 (장변 ÷ 단변 ≤ **2.0**) | **장변 1600px** | 4032×3024 → 1600×1200 |
| 긴 이미지 (비율 > 2.0) | **단변 1200px**, 장변 최대 **6000px** | 612×2900pt 포스터 → 1200×5686 |

- 원본보다 **키우지 않는다** (작은 이미지는 그대로 둔다)
- 긴 이미지를 장변으로 줄이면 폭이 뭉개져 글씨가 안 읽힌다 → 단변 기준이 필요하다
- 갤러리 타일은 CSS 로 정사각 크롭(`object-fit:cover`)이라 원본 비율과 무관하다
- 라이트박스에서 비율 2:1 초과 이미지는 **폭에 맞추고 세로 스크롤**, 나머지는 화면
  높이에 맞춘다 (`data-tall` 속성으로 구분)

## 영상

| 항목 | 값 |
|---|---|
| 컨테이너/코덱 | **MP4 / H.264 (libx264)**, `yuv420p`, `-preset slow` |
| 크기 | **장변 1280px** (가로 영상 1280×720, 세로 영상 720×1280) |
| 품질 | **CRF 30** |
| 오디오 | AAC **96kbps** |
| 스트리밍 | `-movflags +faststart` (앞부분만 받아도 재생 시작) |

- 가로만 재면 세로 영상이 오히려 커지므로 **장변** 기준으로 맞춘다
- 움직이는 GIF 도 MP4 로 변환한다 (`fivedoors.gif` 8.7MB → 0.08MB)
- 갤러리에서 영상 타일에는 **▶ 아이콘 + "영상" 배지**를 얹어 이미지와 구분한다

## PDF

원본 PDF 는 공개본에 넣지 않는다. **페이지마다 JPEG 한 장**으로 뽑아
`<이름>_pages/page-001.jpg` 형태로 저장하고, 갤러리에는 `이름 (PDF n쪽)` 으로 묶어
보여준다.

- 래스터화 배율은 위 `fit()` 목표 크기에서 역산한다 (원본 대비 **3배 확대 상한**)
- 마크다운 안의 PDF 링크는 첫 페이지 이미지로 바꿔 쓴다
- 94MB 짜리 PDF 하나가 저장소의 1/3 을 차지하던 문제를 이걸로 없앴다

## 한글 파일명 (NFC/NFD) — 반드시 지킬 것

맥 파일시스템은 한글 이름을 **NFD**(자모 분리)로 돌려주는데 git 은 커밋할 때
**NFC**(완성형)로 저장한다. 로컬 경로를 그대로 링크에 쓰면 파일은 올라가 있는데도
GitHub Pages 가 **404** 를 낸다.

- `_site.py` / `_optimize.py` 는 링크를 항상 NFC 로 적는다
- `_checkrefs.py` 는 로컬 파일이 아니라 **`git ls-files`** 와 대조해 이걸 잡는다
- 노션 zip 은 `unzip` 이 아니라 **`ditto -x -k`** 로 푼다 (`unzip` 은 한글 이름을
  아예 깨뜨린다 — Illegal byte sequence)

## GitHub 무료 계정 한도

| 한도 | 현재 |
|---|---|
