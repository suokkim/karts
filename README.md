## 구성

```
index.html          학기 목록
<연도>-<학기>/
  index.html        해당 학기 갤러리
  index.md          노션 원본 페이지 본문
  *.csv             학기 제출 목록 (노션 데이터베이스)
  <작품폴더>/       이미지 · 영상
```

이미지는 JPEG(장변 1600px), 영상은 H.264 720p 로 경량화했다. PDF 는 페이지마다
JPEG 로 뽑아 `<이름>_pages/` 에 넣었다. 원본은 로컬에 따로 보관한다.
